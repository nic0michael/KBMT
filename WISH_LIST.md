# Wish List

The following features are proposed for future development.
1.	Knowledge Base ZIP Import
·	Upload a ZIP file.
·	Automatically create a Knowledge Base.
·	Extract and import the supplied content.
·	Preserve folder structures and document relationships.
·	Validate the ZIP contents before importing.

2.	Automated Daily Backups
·	Generate daily backups automatically.
·	Allow backups to be downloaded and stored on a VM server.
·	Support configurable backup schedules.
·	Provide backup retention policies.

3.	Database Backup and Restore
·	Download database backups.
·	Upload existing backups.
·	Restore a Knowledge Base from a backup.
·	Validate backup files before restoration.

4.	Markdown and HTML Support
·	Support Markdown documents.
·	Support HTML content.
·	Provide a readable document presentation.
·	Support code blocks, tables, images and diagrams.
·	Provide Markdown preview functionality.

4.	Mobile-Friendly Application
·	Provide a responsive interface for mobile phones and tablets.
·	Make it easy to browse and read Knowledge Bases.
·	Consider a Progressive Web App (PWA) before developing separate Android and iOS applications.

5.	Search Functionality
·	Full-text searching across Knowledge Bases.
·	Search by document title, keywords and content.
·	Filter results by Knowledge Base and category.

6.	Document Navigation
·	Hierarchical document navigation.
·	Categories and subcategories.
·	Previous and next document navigation.
·	Table of contents for longer documents.

7.	Knowledge Base Versioning
·	Maintain document revision history.
·	Allow administrators to compare previous versions.
·	Restore an earlier version.

8.	Content Attachments
·	Upload images, PDFs and supporting documents.
·	Include diagrams and downloadable resources.
·	Manage attachments centrally.

9.	Import and Export
·	Export an entire Knowledge Base.
·	Export individual articles.
·	Support Markdown and ZIP export formats.
